# js-algorithms 
учебный репозиторий: модуль "Алгоритмика". 
## Что внутри 
- `homework.md` - мои цели на модуль и конспекты статей 
- `string-utils/1` - 7 функций сравнения строк, реализованы путём TDD; 
   - `is-equal.js` - равны ли строки
   - `is-less.js` - лексикографически меньше 
   - `is-lessOrEqual.js` - меньше или равны 
   - `is-more.js` - лексикографически больше 
   - `is-moreOrEqual.js` - больше или равны 
   - `is-notEqual.js` - неравенство строк 
   - `len.js` - длина строки 
### Все функции покрыты тестами, носящими соответствующие названия
тесты запускаются командой `bun test` из терминала (не забываем перейти в соответствующую директорию)
