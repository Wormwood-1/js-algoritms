# js-algorithms 
учебный репозиторий: модуль "Алгоритмика". 
## Что внутри 
- `homework.md` - мои цели на модуль и конспекты статей 
- `string-utils/` - 21 функция для работы со строками, реализованы путём TDD; 
   - `is-equal.js` - равны ли строки
   - `is-less.js` - лексикографически меньше 
   - `is-lessOrEqual.js` - меньше или равны 
   - `is-more.js` - лексикографически больше 
   - `is-moreOrEqual.js` - больше или равны 
   - `is-notEqual.js` - неравенство строк 
   - `len.js` - длина строки 
   - `endsWith.js` - проверка конца строки
   - `includes.js` - проверка наличия подстроки
   - `index-of.js` - наивный поиск подстроки
   - `lowerCase.js` - в нижний регистр через коды символов 
   - `pad.js` - дополнение до длины
   - `repeat.js` - повторение строки
   - `replace.js` - замена первого вхождения
   - `replaceAll.js` - замена всех вхождений
   - `reverse.js` - переворот строки
   - `slice.js` - подстрока с отрицательными индексами
   - `startsWith.js` - проверка начала строки
   - `substring.js` - подстрока с нормализацией индексов
   - `trim.js`- обрезка пробелов с краёв
   - `upperCase` -  в верхний регистр через коды символов 
- `helpers/` - все вспомогательные функции, появляющиеся в ходе работы; 
   - `normalizeIndex` - Нормализует индекс для использования в строках
   - `normalizeArrayIndex` - Нормализует индекс для использования в массивах
- `array-utils/` - 15 функций для работы с массивами, реализованы путём TDD; 
   - `includes` для массивов — через композицию с indexOf
   - `lastIndexOf` — поиск последнего вхождения
   - `indexOf` для массивов — поиск элемента
   - `shift` — удаление первого элемента со сдвигом
   - `unshift` — добавление в начало со сдвигом
   - `pop` — удаление последнего элемента
   - `push` — добавление в конец массива
   - `at` — доступ по индексу с отрицательными индексами
   - `len` для массивов — подсчёт элементов 
   - `fill` (arr, value, start, end) — заполнение значением (мутирует)
   - `reverse` (arr) — переворот на месте, алгоритм двух указателей (мутирует)
   - `concat` (arr1, arr2) — объединение в новый массив (иммутабельная)
   - `slice` (arr, start, end) — копирование подмассива (иммутабельная)
   - `join` (arr, separator) — склеивание в строку (иммутабельная)
   - `splice` (arr, start, deleteCount, ...items) — удаление и вставка (мутирует) 
   - `forEach` (arr, callback) — перебор, вызов callback для каждого элемента
   - `map` (arr, callback) — трансформация, новый массив из результатов callback
   - `filter` (arr, callback) — фильтрация по предикату, новый массив
   - `some` (arr, callback) — «хотя бы один» с ранним выходом при true
   - `every` (arr, callback) — «все» с ранним выходом при false

### Все функции покрыты тестами, носящими соответствующие названия
тесты запускаются командой `bun test` из терминала (не забываем перейти в соответствующую директорию)
