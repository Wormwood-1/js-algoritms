# js-algorithms 
учебный репозиторий: модуль "Алгоритмика". 
## Что внутри 
- `homework.md` - мои цели на модуль и конспекты статей 
- `string-utils/` - 21 функция для работы со строками, реализованы путём TDD; 
   - `is-equal.js` - равны ли строки
   - `is-less.js` - лексикографически меньше 
   - `is-lessOrEqual.js` - меньше или равны 
   - `is-more.js` - лексикографически больше 
   - `is-moreOrEqual.js` - больше или равны 
   - `is-notEqual.js` - неравенство строк 
   - `len.js` - длина строки 
   - `endsWith.js` - проверка конца строки
   - `includes.js` - проверка наличия подстроки
   - `index-of.js` - наивный поиск подстроки
   - `lowerCase.js` - в нижний регистр через коды символов 
   - `pad.js` - дополнение до длины
   - `repeat.js` - повторение строки
   - `replace.js` - замена первого вхождения
   - `replaceAll.js` - замена всех вхождений
   - `reverse.js` - переворот строки
   - `slice.js` - подстрока с отрицательными индексами
   - `startsWith.js` - проверка начала строки
   - `substring.js` - подстрока с нормализацией индексов
   - `trim.js`- обрезка пробелов с краёв
   - `upperCase` -  в верхний регистр через коды символов 
- `helpers/` - все вспомогательные функции, появляющиеся в ходе работы; 
 - `normalizeIndex` - Нормализует индекс для использования в строках
 
### Все функции покрыты тестами, носящими соответствующие названия
тесты запускаются командой `bun test` из терминала (не забываем перейти в соответствующую директорию)
